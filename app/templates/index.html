Convertir
a GeoParquet

Convierte una capa GeoJSON, GeoPackage o Shapefile a GeoParquet conservando su CRS.

Para Shapefile, selecciona juntos los archivos .shp, .shx y .dbf. Si el GeoPackage contiene varias capas se convertirá la primera.

Reproyectar
Capa

Selecciona una capa con CRS definido y especifica el código EPSG de destino. El resultado conservará el formato de origen.

Para Shapefile, selecciona juntos los archivos .shp, .shx y .dbf. El resultado se descargará como un archivo ZIP.
